# 제품 기능

아래 내용은 분리된 환경의 테스트를 포함한 구현된 업무 흐름을 소개합니다. 모든 기능의 운영 승인 또는 상용 제공을 의미하지 않습니다.

| 영역 | 제품 경험 |
| --- | --- |
| 수련생 관리 | 담당자가 권한이 있는 도장 범위에서 수련생 프로필과 등록·갱신 이력을 검토합니다. |
| 직원 권한 | 서버에서 도장별 권한을 확인하며 직원 관리와 제한된 체크인을 구분합니다. |
| 수련생 ID | 안정적인 QR 인증 정보와 인쇄 카드를 구분합니다. 승인된 사진이 없어도 NO PHOTO 표시로 ID를 제공합니다. |
| ID 표시 | 도장별 템플릿, 인쇄용 대분류 등급, 배지 및 승인된 크기를 지원하며 기본 크기는 2.5 × 3.5인치입니다. 정확한 승급 정보는 별도로 관리합니다. |
| 출석 | 예약 출석과 현장 방문을 구분합니다. 여러 수업 출석을 지원하며 동일 수련생·수업의 반복 확인은 중복 출석을 생성하지 않습니다. |
| 체크인 개인정보 | 최소한의 수련생 식별 정보와 일반 안내만 표시하며 보호자·비공개·비용 상세 정보는 제한 화면에 노출하지 않습니다. |
| 검토 기반 가져오기 | Excel 검토에서 빈 업데이트는 기존 유효 정보를 유지합니다. ZIP 사진 연결에는 범위가 지정된 식별자 또는 명시적 연결과 담당자 검토를 사용하며 원본·처리본·승인본을 구분합니다. |
| 납부 관련 관리 | 도장별 비용 설정과 명시적 부과 이력은 당시 조건을 유지합니다. 설정 활성화만으로 채무가 생성되거나 결제되지 않습니다. |
| 등록·갱신 문서 | 담당자가 원본과 이력을 검토하며 문서 업로드와 등록·갱신 확인은 별도 절차입니다. |

## 범위

결제 처리, 자동 청구, 얼굴 인식 및 모바일 지갑 패스는 제외합니다. 학부모·가족 포털, 네이티브 모바일 앱 및 Meta/AI 마케팅은 보류 상태입니다.
