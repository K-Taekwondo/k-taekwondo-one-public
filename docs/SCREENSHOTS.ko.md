# 화면 및 미디어 공개 정책

공개 갤러리에는 2026년 10월 14일 운영자 요청에 따라 게시한 가상 기록 기반의 로컬 애플리케이션 화면 3개가 포함됩니다. 백엔드 또는 실제 계정에 연결하지 않았습니다. 공개를 위해 사진과 QR 형태의 장식 아이콘을 제외했습니다. 기존 영어 UI에 이중 언어 시연 표시를 추가했으며 설명은 두 언어로 제공합니다. 운영 준비 완료를 의미하지 않습니다.

## 공개 전 확인

1. 가상의 이름과 데이터만 사용합니다. 수련생 사진, 보호자 정보, 출석 이력, 등록 문서 또는 내보내기 자료를 재사용하지 않습니다.
2. 시연용을 포함한 모든 QR 코드와 바코드를 공개 미디어에서 제외합니다.
3. 내부 주소, 프로젝트 식별자, 직원 계정, 브라우저 UI, 알림 및 계정 메뉴를 제외합니다.
4. 최종 이미지를 단일 평면으로 만들고 메타데이터, 숨김 레이어, 썸네일 및 첨부물을 제거합니다. 자르기나 흐림 처리만으로 충분하지 않습니다.
5. 실제 내보내기 파일의 표시 내용과 메타데이터를 검토하고 성격에 따라 “가상 시연” 또는 “콘셉트”로 표시합니다.
6. 운영자가 허용한 범위에서 검토한 파일만 게시합니다. 콘셉트 이미지를 출시 기능처럼 표현하지 않습니다.

비공개 화면을 이슈에 첨부하지 마세요. 민감한 자료가 실수로 공개되면 추가 게시를 중단하고 운영자에게 비공개로 알립니다. 삭제만으로 Git 이력이나 복사본까지 제거된다고 보장할 수 없습니다.
