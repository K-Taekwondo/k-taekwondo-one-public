# Product capabilities | 제품 기능

These descriptions summarize implemented product workflows, including isolated testing. They are not a claim that every workflow is approved for production or commercially available.

아래 내용은 분리된 환경의 테스트를 포함한 구현된 업무 흐름을 소개합니다. 모든 기능의 운영 승인 또는 상용 제공을 의미하지 않습니다.

| Area / 영역 | Product experience / 제품 경험 |
| --- | --- |
| Student workspace / 수련생 관리 | Staff manage student profiles and review membership history within authorized studio scope. / 담당자가 권한이 있는 도장 범위에서 수련생 프로필과 등록·갱신 이력을 검토합니다. |
| Staff permissions / 직원 권한 | Server-enforced studio permissions separate staff administration from restricted check-in. / 서버에서 도장별 권한을 확인하며 직원 관리와 제한된 체크인을 구분합니다. |
| Student IDs / 수련생 ID | Stable QR credentials are separate from printable cards. An ID view remains available without an approved photo, using NO PHOTO. / 안정적인 QR 인증 정보와 인쇄 카드를 구분합니다. 승인된 사진이 없어도 NO PHOTO 표시로 ID를 제공합니다. |
| ID presentation / ID 표시 | Studio-owned templates, broad printed rank categories, badges, and authorized dimensions; default cards measure 2.5 × 3.5 inches. Exact progression remains separate. / 도장별 템플릿, 인쇄용 대분류 등급, 배지 및 승인된 크기를 지원하며 기본 크기는 2.5 × 3.5인치입니다. 정확한 승급 정보는 별도로 관리합니다. |
| Attendance / 출석 | Reserved arrivals and walk-ins are distinct. Multiple sessions are supported; repeated confirmation for the same student and session does not create duplicate attendance. / 예약 출석과 현장 방문을 구분합니다. 여러 수업 출석을 지원하며 동일 수련생·수업의 반복 확인은 중복 출석을 생성하지 않습니다. |
| Check-in privacy / 체크인 개인정보 | Minimal student identity and a generic office alert; guardian, private, and fee details remain outside the restricted view. / 최소한의 수련생 식별 정보와 일반 안내만 표시하며 보호자·비공개·비용 상세 정보는 제한 화면에 노출하지 않습니다. |
| Reviewed imports / 검토 기반 가져오기 | Excel review preserves good data when updates are blank. ZIP photo matching uses scoped identifiers or explicit mappings and human review, with separate original, processed, and approved photos. / Excel 검토에서 빈 업데이트는 기존 유효 정보를 유지합니다. ZIP 사진 연결에는 범위가 지정된 식별자 또는 명시적 연결과 담당자 검토를 사용하며 원본·처리본·승인본을 구분합니다. |
| Obligations / 납부 관련 관리 | Studio-owned fee settings and explicit assignments retain historical terms. Enabling a setting does not automatically create debt or collect payment. / 도장별 비용 설정과 명시적 부과 이력은 당시 조건을 유지합니다. 설정 활성화만으로 채무가 생성되거나 결제되지 않습니다. |
| Membership documents / 등록·갱신 문서 | Staff review originals and history; document upload and membership confirmation are separate actions. / 담당자가 원본과 이력을 검토하며 문서 업로드와 등록·갱신 확인은 별도 절차입니다. |

## Boundaries | 범위

Payment processing, automatic charges, facial recognition, and wallet passes are excluded. Parent/family portals, native mobile apps, and Meta/AI marketing remain deferred.

결제 처리, 자동 청구, 얼굴 인식 및 모바일 지갑 패스는 제외합니다. 학부모·가족 포털, 네이티브 모바일 앱 및 Meta/AI 마케팅은 보류 상태입니다.
