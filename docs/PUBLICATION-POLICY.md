# Public disclosure rules | 공개 자료 관리 원칙

This repository contains newly authored product documentation only. It is not a mirror, export, source release or deployment target for the private application.

이 저장소에는 새로 작성한 제품 소개 문서만 포함합니다. 비공개 애플리케이션의 미러, 내보내기, 소스 공개 또는 배포 대상이 아닙니다.

## Allowed content | 허용 자료

Reviewed English/Korean product descriptions, clearly qualified roadmap and business proposals, and separately approved synthetic-only media following the screenshots policy.

검토된 영어·한국어 제품 설명, 상태가 명확히 표시된 로드맵과 사업 제안 및 화면 공개 정책에 따라 별도 승인된 가상 미디어를 허용합니다.

## Excluded content | 제외 자료

Application source, compiled bundles, database definitions, migrations, internal architecture/runbooks, private history, environment files, credentials, tokens, internal service addresses, student or guardian information, real portraits, exports and credential-bearing documents. No application workflow or deployment configuration belongs here.

애플리케이션 소스, 빌드 결과물, 데이터베이스 정의, 마이그레이션, 내부 아키텍처·운영 지침, 비공개 이력, 환경 파일, 인증 정보, 토큰, 내부 서비스 주소, 수련생·보호자 정보, 실제 사진, 내보내기 자료 및 인증 정보가 포함된 문서는 제외합니다. 애플리케이션 워크플로나 배포 설정도 포함하지 않습니다.

## Publication review | 게시 검토

Review every exact file and staged change, check sensitive patterns and links, and inspect history before publishing. Automated pattern checks supplement manual review; they cannot guarantee the absence of all sensitive content. Never copy private repository history or automatically synchronize private files.

게시 전에 모든 실제 파일과 스테이징 변경을 검토하고 민감한 패턴·링크 및 이력을 확인합니다. 자동 패턴 검사는 수동 검토를 보조하며 모든 민감 정보의 부재를 보장하지는 않습니다. 비공개 저장소 이력을 복사하거나 비공개 파일을 자동 동기화하지 않습니다.

Initial publication scope: six Markdown documentation files, no screenshots, no source files, no deployment workflows. Future changes require the same disclosure review.

최초 공개 범위는 Markdown 문서 6개이며 화면 이미지, 소스 파일 및 배포 워크플로는 없습니다. 향후 변경에도 동일한 공개 검토를 적용합니다.
