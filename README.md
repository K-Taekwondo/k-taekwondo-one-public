# K-Taekwondo One

**Studio operations, thoughtfully connected.**  

K-Taekwondo One is a studio operations product in development, shaped around the daily work of Taekwondo instructors and office teams: student administration, class attendance, student IDs, and reviewed operational workflows.

> This is a documentation-only product showcase. Application source, internal infrastructure, credentials, and student records are not distributed here. Selected workflows have been exercised in isolated testing; full production release validation remains pending. This repository does not announce general availability.

## Product principles

- **Studio control:** permissions, ID presentation, and operational settings belong to each studio.  
- **Clear attendance:** a reservation and an actual arrival are separate events.  
- **Stable identity:** routine profile or card design changes do not change the student’s QR credential.  
- **Limited check-in visibility:** the check-in experience shows only the identity needed for arrival and a generic office alert.  
- **Human review:** imports, photo matching, and membership confirmations retain staff review.
